
# Learning_ML

This repository contains the resources and exercises I have worked on while learning Machine Learning. It includes Jupyter Notebooks covering a variety of machine learning topics, from supervised to unsupervised learning, including algorithms like Support Vector Machines, Decision Trees, Random Forests, and Dimensionality Reduction techniques.

## Contents

- **Decision Trees**: Exercises and implementations
- **Dimensionality Reduction**: Techniques for reducing feature space
- **Support Vector Machines**: Hands-on exercises
- **Ensemble Learning & Random Forests**: Implementation and theory
- **Unsupervised Learning**: Algorithms and applications
- **Model Training**: Methods for training and validating ML models

## Usage

- Clone the repository to your local machine:
  ```
  git clone https://github.com/lalit-jamdagnee/Learning_ML.git
  ```
- Navigate into the repository:
  ```
  cd Learning_ML
  ```
- Open any `.ipynb` file in Jupyter Notebook to explore the exercises.

## Learning Path

This repository is designed as a learning guide, so feel free to contribute your own exercises and implementations of machine learning algorithms!
